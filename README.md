# EASA Part-66 Module 3 Study Pages

Static pages (no build step). Open `index.html` or serve with GitHub Pages.

- `index.html` hub
- `mock.html` timed mock exam, 45 questions
- `practice.html` extra practice, 61 questions
- `guide.html` answers and explanations to read through

All pages support TH/EN, night mode, and text size. Progress is stored in the browser (localStorage).
